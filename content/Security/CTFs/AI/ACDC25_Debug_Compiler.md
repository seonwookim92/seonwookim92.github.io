아마 좌측에 있는게 기본 예제 코드로 보인다.
주요 Operator 들이 한글로 치환되어 있는 것으로 보이고, 브라켓(`{}`)을 사용하는 것으로 보인다.

문법을 아래와 같이 정리해볼 수 있다.

### 디귿 언어 문법

#####  기본 구조 
```
# 주석 
변수 = 값 
함수 이름(매개변수) { ... } 
```

##### 주요 키워드
- `함수`: 함수 선언 
- `반환`: 함수 반환값 
- `동안`: while 반복문 
- `만약` / `아니면`: if/else 조건문 
- `출력`: 문자열 출력 (자동 newline 추가) 
- `출력문자`: 단일 문자 출력 (newline 없음) 
- `입력`: 표준입력 읽기

##### 내장 함수 
- `문자(코드)`: ASCII/Unicode 코드를 문자로 변환 
- `코드값(문자)`: 문자를 코드값으로 변환 
- `길이(문자열)`: 문자열 길이 반환

##### 특수 문자 코드 
- `문자(34)` = `"` (따옴표) 
- `문자(59)` = `;` (세미콜론)
- `문자(115)` = `s` 
- `문자(61)` = `=`
